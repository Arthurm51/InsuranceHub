Branches:
feat/ para funcionalidade, test/ para automação, docs/ para documentação de QA, ci/ para pipeline.
Acrescentar chore/ para configuração e fix/ para correções.

Formato: test/123-login-api, com o número da issue.

Commits: tipo(escopo): descrição no imperativo. Exemplo: test(api): cobre bloqueio de login após 5 tentativas.

PRs: um PR por entrega, ligado à issue com Closes #N e integrado com squash merge. Em Settings → General, deixe só squash habilitado e marque "Automatically delete head branches".
